# Getting help

- **Questions and ideas:** open an issue with the "Feature idea" form, or ask in the Herdr community.
- **Something broken:** use the "Bug report" form. Include the engine log
  (`~/.config/herdr-app/data/webtab/webtabd.log`) and your OS, Herdr and browser versions.
- **Guard blocked something it shouldn't (or missed something):** use the "Guard rule problem" form.
- **Security problems:** report them privately, as described in [SECURITY.md](SECURITY.md).

Start with the [README](README.md) and [docs/how-it-works.md](docs/how-it-works.md); most setup
questions are answered there. This is a volunteer project, so replies may take a few days.
